# Digital Saathi: story-based lessons (Step 00 and all six steps)

Every learning point of the six steps has a **story page**: a short real-life story, a *what if?*, four set-up steps, an
interactive activity with a badge, real-life benefits and a reflection question. Each page exists in **English, Hindi and Marathi**.

**Folders:** one folder per language, and inside each one a folder per step. File names are the same in all three languages.

| Language | Folder | Contents |
|---|---|---|
| English | [`english/`](english/README.md) | 47 story pages + the six full Step 01 lessons (`full-lessons/`) |
| हिंदी | [`hindi/`](hindi/README.md) | 47 story pages |
| मराठी | [`marathi/`](marathi/README.md) | 47 story pages |

- Step 01 also has the *full lessons* (infographic prompt, 9-question quiz, badge, learning objectives) in English: see [`english/step-01-smartphone-basics/README.md`](english/step-01-smartphone-basics/README.md).
- Step 00 and Steps 02–06 have story pages only.

## Quality notes

- **41 lessons × 3 languages = 123 story pages.** Every page has the same structure in every language, which was checked automatically.
- **Facts** (menu paths, button presses, numbers like 1930, ages, app names) come from the approved Steps 01–06 on the website.
  The safety tips (for example “never pay an agent for the card”, “keep the PIN secret”) are the author's additions, written to be
