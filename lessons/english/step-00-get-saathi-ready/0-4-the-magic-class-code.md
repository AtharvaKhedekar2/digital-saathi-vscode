# 🔑 The Magic Class Code
*A short code opens the door to your Digital Saathi class.*

---

## 📖 Story: “A Code on a Card”

### Meet Mr. Naidu

👴 Mr. Naidu is 69 years old and lives in Hyderabad. He worries that an “online class” will be too hard.

Kavya, a Digital Saathi volunteer, writes a short **class code** on a card and gives it to him.

“This code is like a key,” she says. “It opens your class.”

Mr. Naidu opens the **Classroom** app and signs in with his Gmail account.

📱 The Classroom app:
- Shows all your classes on one screen
- Keeps your lessons in one place
- Shows the tasks your Saathi gives you

He taps the **+** sign, taps **Join class**, types the code and taps **Join**.
His class appears on the screen. *“That is all?”* he laughs. *“I thought it would be harder.”*

---

## 🤔 What If the Code Does Not Work?

Sometimes the app says the code is wrong. Often one letter or number was typed by mistake.

Mr. Naidu checks each letter and number against the card. If it still fails, he asks Kavya for the code again.

💡 Join the class in your own language. Your Saathi will tell you which code to use.

---

## 🛠️ How To Set It Up

### Step 1: Open Classroom and sign in
📱 Open **classroom.google.com** or the **Classroom app**.
✅ Sign in with your Gmail account.

### Step 2: Tap the + sign
✅ Tap the **+** at the top.
✅ Tap **Join class**.

### Step 3: Type the class code
✅ Type the code from your Saathi, slowly.
✅ Tap **Join**.

### Step 4: Open your class
✅ Your class now appears on the home screen. Tap it to open.
✅ If you have an **invite link** instead, tap the link and then tap **Join**.
